## Design Specificity Verdict

**LLM assessment**：这是一个有明确产品性格的 QA 控制台：记录、证据、下发、裁决是核心，信息密度和表格化是对的。问题不在视觉风格，而在**流程地图没有产品化**——资产、用例、下发、结果之间的依赖靠散落的提示和用户记忆维持。

**Deterministic scan**：`impeccable detect --json src/console` 退出 0，9 个文件 0 findings；但检测器对 `.ts` 只做 regex，不解析模板字符串里的 HTML，所以这是**低召回**结果，不是“视觉无问题”的证明。没有浏览器自动化，无法做页面注入/overlay。

**Visual overlays**：未执行（本会话没有浏览器自动化；没有用户可见 overlay）。

## Overall Impression

快乐路径是通的：上传资产 → 下发 → 任务详情 → 结果/证据。真正的问题是**跨版块知识**：用户必须知道“安装包在哪里”“重新派发是不是同一个东西”“参考图为什么传不上”。单点最大机会：把资产中心做成一级目的地，并让每个“重新执行/上传/查看”动作在自己的页面闭环。

## What's Working

- 网页任务提交后直接跳到具体 job 详情，有 flash、返回列表、关联任务链接；不是死路。
- 任务取消/停止/重新派发、定时任务删除都有站内确认，危险动作可审计。
- 设备空状态给了 runner 下载、工具链下载和分步指引，是真正可行动的 empty state。

## Priority Issues

### [P1] Web 任务的“重新派发”静默创建了一个空套件任务

**Where**：`src/console/pages.ts:1226-1228`、`src/panel/web.ts:2450-2451`、`src/panel/actions.ts:2565-2588`、`src/web/jobs.ts:241-252`

**What**：Web job 详情页提供“重新派发”。`rerunTask` 只复制 `refs/platforms/baseline`，不复制 `jobSpec`、`executionMode`、资产、设备钉选和 caseFilter。Web job 创建时 `refs` 是空的，所以新任务不会出现在 `section=jobs`，也不会走 Web/Maestro 执行器。用户看到“已重新派发新任务”，但实际得到一个空套件任务。

**Why it matters**：这是静默错误，不是小摩擦；用户会以为 Web 测试重跑了。

**Fix**：对 `task.jobSpec != null` 隐藏“重新派发”，换成“重新下发网页测试”（预填 spec），或实现 Web-aware clone 并重新校验资产快照；关联任务链接改名为“打开关联回归任务（仅执行状态）”。

### [P1] “参考图（L2 reference）”上传是死路径

**Where**：`src/console/pages.ts:307-309`、`src/console/pages.ts:360`、`src/panel/web.ts:688-694`

**What**：上传类型有“参考图”，文件选择也接受 `.png/.jpg/.jpeg/.webp`，但前端 `uKind()` 只认 `package/materials`，其余一律回落 `excel`；`uKindOf` 没有图片分支，`uExtOk` 随后用 Excel 规则拒绝图片。即使 API 上传了 reference，资产页也没有 reference 列表。

**Why it matters**：L2 参考物是设计的一部分，但入口看起来存在、实际不可用。

**Fix**：让 `uKind`/`uKindOf`/`uExtOk` 支持 `reference`；资产页加载并展示 reference 表格；补一条 E2E 断言“选参考图 + PNG 能上传”。

### [P2] Excel 上传入口仍会随“已有 Excel”消失

**Where**：`src/console/pages.ts:958-964`、`src/console/pages.ts:1000-1010`

**What**：与刚修的安装包同类：`excelHint` 只在没有 Excel 资产时渲染；已有 Excel 后，下拉旁没有“上传新 Excel”，只剩页面 lede 里的“测试资产”链接。

**Why it matters**：每个版本/迭代上传新 Excel 是常态，用户会再次找不到入口。

**Fix**：照安装包的做法，在 Excel 下拉旁常驻“上传新 Excel”链接（`section=assets&kind=excel#asset-upload`），空状态提示只作为补充。

### [P2] “测试资产”没有一级入口，且导航高亮与页面不一致

**Where**：`src/console/shell.ts:112-123`、`src/panel/web.ts:3504-3511`、`src/console/pages.ts:367-368`、`src/console/pages.ts:881-884`

**What**：导航没有“测试资产”。进入测试资产页时侧栏高亮“用例库”；进入网页测试时侧栏高亮“套件回归”，而页面自己的 flow switch 显示“网页测试”激活。`jobs` 导航项几乎不会成为 `aria-current`。

**Why it matters**：用户无法从导航建立“资产属于哪里”的地图，也不知道自己当前在哪。

**Fix**：增加项目级 `assets` 导航项；`web-assets` 映射 `assets`，`web-jobs/web-job` 映射 `jobs`；统一命名（导航“网页测试（安装包）” vs 页面“下发测试” vs 详情“下发任务详情”）。

### [P2] 失败分析是死路：不能打开运行/任务，空状态也没有下一步

**Where**：`src/panel/web.ts:2527-2551`、`src/panel/web.ts:2558-2563`、`src/panel/web.ts:2660-2663`、`src/panel/overview.ts:1561-1568`

**What**：失败用例表把 `runId` 渲染成普通 `<code>`，case ID 也没有链接；`buildPanelReviewQueue` 已经读到 `regressionTaskId` 但没暴露。空状态只说“完成下发后此处会列出失败用例”，没有“去下发”链接；复跑仍是 CLI 片段。

**Why it matters**：QA 看到失败后最自然的动作是打开产生这次失败的任务/批次，现在必须离开页面自己找。

**Fix**：在 review item 上暴露 `regressionTaskId`；run ID 链接到 task/batch；空状态加“去下发”；处理路径加“重新下发”链接。

## Persona Red Flags

**Alex（Power User）**：从 Web job 详情点“重新派发”，以为重跑 Web 测试，实际得到一个空套件任务；没有从测试资产页直接回到网页测试的常驻路径。

**Jordan（First-Timer）**：“安装包 / 测试资产 / 用例库 / 网页测试 / 下发测试”是五套词；在用例库找不到安装包，在网页测试找不到上传，在测试资产又不知道自己在哪（侧栏高亮用例库）。

**Sam（Accessibility-Dependent）**：导航 active 状态与页面不一致，屏幕阅读器无法靠 `aria-current` 判断当前位置；部分禁用控件没有就地说明原因，只能看到 disabled。

## Minor Observations

- 角色导致的禁用仍写成“独立进程需 AOS_PANEL_ACTIONS=1”：`src/console/pages.ts:64-69`、`src/console/dispatch.ts:764-779`、`src/panel/web.ts:2421-2425`、`src/console/pages.ts:1884-1894`。HTTP 下的 dispatcher/viewer 会得到错误原因；导出是只读动作，也不该叫“写动作未启用”。
- 档案时间预设保留当前 `offset`，在第 3 页点“近 24 小时”会得到空页：`src/console/pages.ts:1428-1441`、`1460-1461`。
- Web 任务项目选择器把当前 host 套到所有项目链接：`src/console/pages.ts:899`、`src/panel/web.ts:606-613`；选到其他 host 的项目会解析失败。
- 审计里的“用例库 <id>”没有锚点/过滤，用例库也不显示 ID：`src/console/pages.ts:1535-1537`、`src/console/pages.ts:156-158`。
- 套件回归切 host 只保留 project/section/host，丢掉 source/ref/keyword/platforms/baseline：`src/console/dispatch.ts:803`。
- 脚本生成控件在任一资产列表为空时整体 disabled，但按钮旁没有原因：`src/console/pages.ts:334-335`。
- 资产版本卡的“导入用例库”在 dispatcher 下 disabled，但卡片内没有角色说明：`src/console/pages.ts:233`、`318`。
- 审计的 `#schedules` 链接在 empty-project 分支可能指向关闭的 `<details>`：`src/console/pages.ts:1539`、`src/panel/web.ts:2973-2976`。
- Web job 写回只显示单元格数量，不显示写回的是哪份 Excel/版本：`src/console/pages.ts:1166-1181`、`1230-1266`。
