## Priority Issues

### [P1] 单次运行失败仍被藏起来

项目页有 3 条失败 + 1 条运行中的“单次运行”，但它们在 `<details>环境自查与明细` 里；失败分析只统计套件运行，所以显示 0；compare 说“失败 0，单次运行见项目页”。用户无法判断哪个数字是真的。

**修复**：把单次运行提升为一级 section/tab；失败分析要么合并单次运行失败，要么明确叫“套件回归失败分析”并给“另有 N 条单次运行失败 → 档案”的显式 callout；trace ID 可点。

### [P1] 档案关联过滤对未知 task/run 静默返回全量

`?task=fake-task` 仍显示 17 组/25 文件。原因是 lookup 失败后 `needles` 为空，过滤条件消失。用户最需要过滤时（任务被清理/输错 ID）反而看到全部。

**修复**：解析失败时显示 0 行 + 明确 warning + 清除入口；正/负/已删除三种情况都测试。

### [P1] 1440px 表格仍裁掉右列

compare 的“执行”列在 1440px 只露约 10px；devices 表格 974/786，租约/工具被裁；滚动提示只按视口显示，桌面宽度下隐藏。

**修复**：按实际 `scrollWidth > clientWidth` 显示提示；compare 减少最小宽度/允许换行；devices 折叠右侧说明或把工具/心跳放进展开行；1280/1440/1680 验证。

### [P2] 表单与 host 身份不一致

ops 的 LLM 名称/模型/Base URL、Jira 站点/邮箱，以及 tasks 搜索框没有 `type`，渲染成原生黑框；host 在设备页是 `win-runner-01`/`CN2368578W1`，下发页叫 `CN2368578W1`，warning 叫 `win-runner-01`；设备页带 project 仍隐藏项目导航；设备“去下发”不带设备 serial。

**修复**：无 `type` 输入纳入 CSDC 样式；统一显示 `win-runner-01 (CN2368578W1)`；设备页保留项目 nav；明确“自动选设备”或携带设备。

### [P2] Ops/资产是写-only 死端

ops 配置表单对非 admin 仍可输入后 403；Figma/Jira 没有已配置状态；资产 Excel/包/资料只能上传/导入，不能打开/下载。

**修复**：按角色提前禁用/说明；显示每个集成的 masked 状态；给非 secret 资产安全下载/打开入口。
