# 使用统计只采集客户端发起的调用

「使用统计」的调用事件只记录客户端通过 MCP 发起的工具调用（stdio 与 HTTP 两个传输），不记录服务内部编排的调用（如套件运行器、差异工具内部调用的 mobile 工具）。理由：内部调用随功能迭代自动增多，会稀释「真实使用」语义并放大噪声；且内部链路的可观测性已有任务台账、日志与产物覆盖，混入同一指标会让两边都失真。分层记录（如新增 source 维度）留待未来真正需要内部可观测时另开通道。

## Considered Options

- 全量采集（含内部编排）：指标语义混杂、噪声随功能迭代增长，拒绝。
- 只在内部代理层采集：会丢掉原生工具与 Figma/pen 工具（它们不经过代理层），覆盖不全，拒绝。

## Consequences

- 服务内部编排自身的问题在本统计中不可见，依赖既有日志/台账排查。
- 若未来要纳入内部调用，需要为事件增加来源维度并做数据迁移，而不是悄悄改变现有口径。
