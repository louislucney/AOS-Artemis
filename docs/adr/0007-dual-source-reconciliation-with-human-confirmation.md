# 交互真相以双源对账 + 人工确认收敛（不设单一权威源）

设计稿（Figma/.pen）、CR 验收标准与真机观测对同一交互可能互相矛盾：设计稿的交互显式性不保证（Figma 常无原型连线、pen 侧当前恒为推断），真机观测是事实但不含「应该怎样」，验收标准是意图但不含页面/元素/跳转细节。因此不指定单一权威来源：设计来源与真机观测双向对账，不一致处与推断升级经人工确认后改判；人工只仲裁不一致，不做全量确认。导航级证据可随观测自动升级，硬断言级必须验收标准或人工确认背书。

## Considered Options

- 设计稿权威：设计常缺交互数据，会把推断当事实（starbucks 现场：22 条推断边全部进入硬断言，第 4 步因设计批注文本假失败），拒绝。
- 验收标准权威：意图层，不含导航细节，无法单独支撑走到某屏，拒绝。
- 真机观测权威：只描述现状、无法表达「应该」；新功能在真机上尚不存在，拒绝。
- 全自动融合无人工：冲突无法裁决，错误会静默传播，拒绝。
